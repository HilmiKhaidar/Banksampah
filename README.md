# Banksampah

Aplikasi Bank Sampah Sekolah dengan frontend Next.js dan backend Express/MySQL.

## Menjalankan aplikasi

- Ikuti petunjuk backend dan migrasi database di [backend/README.md](./backend/README.md).
- Jalankan frontend dari folder `frontend` dengan `npm install` lalu `npm run dev`.
- Jalankan backend dari folder `backend` dengan `npm install` lalu `npm run dev`.

Data akun dan aktivitas disimpan di MySQL. Jangan commit file `.env` atau kredensial akun.
